# Atlas 架构与安全约束（虚构）

## 安全边界

原始内部文档和完整索引不得上传到第三方服务。允许将经过本地检索选出的必要片段发送给已签约的大模型 API，但每次请求必须限制片段数量并记录证据标识。日志不得保存片段全文和 API Key。

## 基础设施

现有环境可以运行 Docker，提供一台 16 核 CPU、64 GB 内存和单张 24 GB 显存 GPU。团队已有 PostgreSQL 和对象存储运维经验，但没有大规模图数据库生产经验。

## 集成约束

首期由 4 人小组在 8 周内交付。方案应优先采用可增量更新、可观测、可回滚的组件，避免为演示引入复杂的分布式调度系统。
