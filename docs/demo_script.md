# 演示视频脚本（3–5 分钟）

黄金场景：为「敏感长文档、每日更新、4 人团队、8 周交付」的企业知识库选择 RAG 技术路线。

| 时间 | 画面 | 口播要点 |
|---|---|---|
| 0:00–0:20 | 打开产品首页 / 一句话痛点 | 企业选 RAG 不是搜论文，而是在隐私、更新、人力约束下做可追溯决策。普通 RAG 只回答“论文说了什么”。 |
| 0:20–0:45 | 资料库页：导入内部约束文档 | 展示虚构 Atlas 约束：18 万文档、35% 长文档、日更 2000、只发命中片段、4 人 8 周、单卡 24GB。 |
| 0:45–1:10 | arXiv 搜索 → 预览摘要 → 导入 RAPTOR/CRAG/FLARE/GraphRAG | 公开论文与内部资料进入同一本地索引，状态 parsed→indexing→ready。 |
| 1:10–1:40 | 创建任务：黄金场景模板 + 权重=100 | 候选 5 条路线；说明只会把命中必要片段发给生成模型。 |
| 1:40–2:10 | 研究过程时间线 | 固定节点：normalize → plan → retrieve → compare → draft → validate → await approval。可取消、可失败恢复。 |
| 2:10–2:40 | 报告评审：展开证据 | 每条结论可展开证据摘录、页码、来源；引用存在率、claim 覆盖率。 |
| 2:40–3:10 | 推荐 + 风险 + 证据不足 + 引用网络 | 展示确定性加权矩阵；引用网络邻居明确标记为“独立证据未验证”。草案仍需人工确认。 |
| 3:10–3:40 | 审批 / 修订 / 下载 Markdown | 最终建议必须人工确认；可导出可分享报告。 |
| 3:40–4:10 | 评测结果 | 同时展示文档级与精确证据级 Recall；引用图弱重排没有收益时如实说明。 |
| 4:10–4:30 | 收束 | 差异化：企业约束驱动 + 证据可追溯 + 隐私最小化 + 人工审批，不是又一个聊天 RAG。 |

录制提示：

- 使用本地模式：`$env:QDRANT_PATH='data/qdrant_local'`
- 先跑 `seed_demo` + `import_golden_papers`，保证资料库有 ready 文档
- 报告若被审批门槛拒绝，可作为“系统拒绝无证据推荐”的加分演示
