# 简历项目描述（可直接粘贴）

**企业技术选型 Agent（ScholarGraph）** · 个人项目

面向企业研发团队的技术情报与选型 Agent：输入业务目标、内部资料与架构约束，融合公开论文（arXiv）与内部文档，生成带证据、风险、成本与 POC 建议的选型报告。

- **架构**：本地混合检索（Ollama embedding + Qdrant 向量 + SQLite FTS5 + RRF）；OpenAlex 引用图（SQLite/Neo4j 只读模板）提供证据链；受控单 Agent 固定工作流调用 DeepSeek/Ollama，仅发送命中的必要片段。
- **业务闭环**：把隐私、更新频率、延迟、团队与成本约束映射为确定性 1–5 分矩阵，按用户权重计算总分；隐私硬约束失败的方案不得成为首选，未映射项明确要求人工复核。
- **可信度**：claim 双层校验（引用 ID 硬校验 + 证据支持软校验）；无引用关键事实、部分支持、冲突或虚构引用均阻断审批；过滤检索文档中的 Prompt 模板并保留 rejected/fail-closed 对照报告。
- **评测**：40 条标注查询消融——hybrid 文档级 R@5=0.83、精确证据 R@5=0.60；无答案拒答 5/5，同时披露抽样可答准确率 6/9；图引用弱重排未提升 Recall，不包装成收益。
- **工程**：任务取消、进程中断恢复、修订版本化、证据按任务隔离；固定版本 Docker Compose、本地 Qdrant 降级与 GitHub Actions；pytest 50+ 覆盖摄取、检索、工作流、决策、claim、图与 API。

关键词：Agent 工作流 · RAG · 混合检索 · 证据可追溯 · 隐私最小化 · 人工审批 · 真实验测
